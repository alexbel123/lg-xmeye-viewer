The webOS runtime provides webos-service on the TV. The native development
FFmpeg executable is a test dependency and is not shipped in the application.

Software video decoder component: Jessibuca 4.0.0
https://github.com/langhuihui/jessibuca
https://www.npmjs.com/package/jessibuca/v/4.0.0

Decoder JavaScript and WebAssembly files are downloaded from the original npm
registry only when the user runs tools/vendor-decoder.py. They are excluded
from this public repository and its source-only release archives. The actual
upstream LICENSE is GNU GPL version 3; the npm metadata's MIT label does not
replace that license. The license text is preserved in app/vendor/decoder/COPYING.
The downloaded package includes decoder sources, build scripts and precompiled
third-party static dependencies. Complete corresponding source and reproducible
builds of those static libraries have not been verified; no decoder binaries
or IPK packages are redistributed in the initial public release.
The local setup script changes only the ES-module export in two generated
loaders to expose a classic worker factory. WebAssembly binaries are unchanged.
The SIMD build uses libavc/libhevc; the scalar build uses FFmpeg video libraries.
See docs/LICENSING.md for distribution scope and outstanding binary-build work.
