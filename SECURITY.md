# Security policy

The current development line is 0.3.x. This is an early project with no guaranteed response-time or long-term support commitment.

Report suspected vulnerabilities using [GitHub private vulnerability reporting](https://github.com/alexbel123/lg-xmeye-viewer/security/advisories/new). Include the affected version, a minimal synthetic reproduction, impact and suggested fix if available. Do not post passwords, hashes, media tokens, private IP/MAC addresses, serial numbers or real CCTV footage in public Issues.

Treat Sofia hashes as passwords. Test only systems you own or are authorized to assess, using dedicated viewing accounts and synthetic fixtures whenever possible. This viewer expects a trusted local/routed network; it is not a secure public-internet recorder gateway.

See [privacy and storage](docs/PRIVACY.md) and [known compatibility limits](docs/COMPATIBILITY.md). A passing secret scan is not a complete security audit or a guarantee that the application has no vulnerabilities.
