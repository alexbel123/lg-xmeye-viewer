# Сборка и установка на LG webOS

[Главная](../README.md) · [English](INSTALL.en.md)

## Что доступно сейчас

Скачайте готовый пакет из [выпуска v0.4.0](https://github.com/alexbel123/lg-xmeye-viewer/releases/tag/v0.4.0): `local.xmeye.viewer_0.4.0_all.ipk` — интерфейс FHD; `local.xmeye.viewer_0.4.0_1280x720.ipk` — интерфейс HD. Проверяйте файл по `SHA256SUMS-v0.4.0.txt`. Это приложение webOS, а не Android APK. Для готового IPK шаг сборки ниже можно пропустить. Сначала прочитайте [совместимость](COMPATIBILITY.md): обычный Developer Mode без root ещё не проверен, включая права записи хранилища сервиса.

## 1. Подготовить компьютер

Установите Git, Node.js 18+ и Python 3.10+. Затем:

```sh
git clone https://github.com/alexbel123/lg-xmeye-viewer.git
cd lg-xmeye-viewer
python tools/vendor-decoder.py
npm install --global @webos-tools/cli
npm run build
```

Команда загрузки декодера обращается к выпуску этого проекта на GitHub и проверяет SHA-256. Сборка создаёт `dist/local.xmeye.viewer_0.4.0_all.ipk`. `npm run build:hd` создаёт вариант с графическим холстом 1280×720. Если CLI не найден, задайте `WEBOS_CLI_DIR` как каталог установленного пакета. PowerShell:

```powershell
$env:WEBOS_CLI_DIR = Join-Path (npm root -g) '@webos-tools/cli'
npm run build
```

## 2. Подготовить телевизор для разработки

Используйте официальную [инструкцию LG Developer Mode](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app). Режим имеет ограниченную сессию и предназначен для разработки. На компьютере создайте профиль телевизора с именем `my-tv`:

```sh
ares-setup-device
ares-novacom --device my-tv --getkey
```

Введите адрес и код сопряжения своего телевизора в интерактивном процессе CLI. Ключи не сохраняйте в каталоге проекта и не прикладывайте к Issues.

## 3. Установить локально собранный пакет

```sh
ares-install --device my-tv dist/local.xmeye.viewer_0.4.0_all.ipk
ares-launch --device my-tv local.xmeye.viewer
```

Эти команды используют официальный CLI; они не означают, что приложение уже проверено во всех ограничениях стандартной установки. Исторический тест выполнялся на телевизоре с root. Если сервис не запускается или не сохраняет настройки, укажите обезличенную ошибку в Issue; поддержка обычной среды требует отдельной проверки.

## 4. Добавить регистратор

В приложении нажмите «Добавить регистратор», введите название, IP, порт DVRIP (обычно 34567), пользователя и пароль самого регистратора. Для нескольких устройств создайте отдельные профили. Пустое поле пароля при редактировании сохраняет прежние данные; «Удалить сохранённые данные входа» очищает их для выбранного устройства.

После подключения откроются первые шесть каналов. Выберите сетку 1/2/4/6 вверху экрана; «Изменить набор» позволяет подписать набор, выбрать камеры и изменить их порядок. Кнопка «Наборы» слева открывает сохранённые сочетания. Если камер в наборе больше, чем окон, используйте страницы или CH+/CH−. Одновременно воспроизводится максимум шесть каналов одного регистратора.

Клик по камере или OK раскрывает её на весь экран, «Назад» возвращает сетку. «Скрыть панели» разворачивает поле камер; меню доступно по кнопке в углу или кнопке меню на пульте. CH+/CH− в раскрытой камере переключают канал. Для сетки включите в регистраторе Extra1 с умеренным разрешением и частотой кадров.

Если телефон видит видео через облако, это не гарантирует доступность IP регистратора с телевизора. Проверьте маршрутизацию между подсетями, порт DVRIP и права просмотра учётной записи. Не публикуйте порт регистратора в интернете ради этого приложения; для удалённого доступа используйте собственную защищённую сеть/VPN.

Удаление приложения может не удалить данные из внешнего каталога сервиса. Очистите сохранённые данные через настройки до передачи телевизора другому владельцу. Подробнее — [приватность](PRIVACY.md).

## Пересобрать декодер из исходников

`python tools/build-decoder.py` собирает FFmpeg и наш адаптер; `npm run test:decoder` сравнивает кадры с эталоном. Нужны Linux/WSL, Python 3.12+ и build-essential. Полные исходники зависимостей находятся в ZIP исходников выпуска. [Команды и закреплённые версии](../decoder/README.md).
